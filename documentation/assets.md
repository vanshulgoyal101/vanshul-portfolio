# Assets Documentation

## Images

`public/images/projects/` holds only images referenced by the site. Unused
files are deleted rather than kept around, because everything in `public/` is
deployed and publicly reachable.

| File | Used by |
| --- | --- |
| `profile2.webp` | About section photo; `Person.image` in the homepage structured data |
| `adbrain.webp`, `adbrain-icon.svg` | AdBrain featured project card and title mark |
| `tiny-arcade.webp` | Tiny Arcade featured project card |
| `nasa-herc.webp` | NASA HERC featured project card |

`node scripts/capture-projects.mjs [adbrain] [tiny-arcade]` refreshes the AdBrain and
Tiny Arcade screenshots from their live sites (see [homepage.md](homepage.md)).

`public/images/profile-avatar.webp` (160×160, about 5 KB) is a face crop of
`profile2.webp` for the article byline (44px) and the end-of-article author
card (64px). It is referenced as `PROFILE.avatar`. To regenerate it after
replacing the photo, run this from the repository root and check the crop:

```bash
node -e "require('sharp')('public/images/projects/profile2.webp').extract({ left: 235, top: 185, width: 360, height: 360 }).resize(160, 160).webp({ quality: 82 }).toFile('public/images/profile-avatar.webp')"
```

## Icons and social images

- `panda.svg`: the source favicon. `panda-32.png`, `panda-192.png`,
  `panda-512.png` and `panda-apple-touch.png` (180×180) are rendered from it
  with `node scripts/generate-icons.mjs`. `index.html` links `panda.svg`,
  `panda-32.png` and the touch icon; `site.webmanifest` lists `panda.svg`,
  `panda-192.png` and `panda-512.png`.
- `favicon.ico`: legacy icon for clients that request `/favicon.ico`
  directly; it is not generated by the script.
- `og-image.png`: the 1200×630 default social card, regenerated with
  `node scripts/generate-og-image.mjs`.
- `public/og/<slug>.png`: per-post social cards generated during `prebuild`
  (not committed).

## Other public files

- `robots.txt`: crawler rules and sitemap locations.
- `site.webmanifest`: web-app manifest.
- `404.html`: GitHub Pages SPA fallback (see [deployment.md](deployment.md)).
- `CNAME`: the custom domain (`vanshul.com`). GitHub uses it only for
  branch publishing (the legacy `npm run deploy`); the Actions deployment
  takes the domain from the Pages settings (see
  [deployment.md](deployment.md#github-settings)).
- `a.js`: first-party analytics beacon for other vanshul.com properties (see
  [analytics.md](analytics.md)).
- `cb7efe94abc5118dde33ac4ec2ddc175.txt`: the IndexNow key file, served from
  the site root so search engines accept the site's submissions (see
  [seo.md](seo.md#indexnow)).
- `fonts/`: the self-hosted Inter, Space Grotesk and JetBrains Mono variable
  fonts (latin and latin-ext `woff2` from Fontsource 5.3.0) with their SIL OFL
  1.1 licences; see [styles.md](styles.md#where-styles-live).
- `sitemap.xml`, `feed.xml` and `llms.txt` are generated during `prebuild` and
  are not committed.

## Adding an image

Prefer WebP, size it for its display frame, add it under
`public/images/projects/`, reference it with a root-relative path
(`/images/projects/name.webp`), and give it meaningful `alt` text or `alt=""`
when decorative.
